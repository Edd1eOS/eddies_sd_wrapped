# Stable Diffusion Workbench

面向本地 Stable Diffusion 图片生成的一站式工作台。目标是把上游开源能力包装成可复用、可诊断、易分发的本地项目，而不是重新实现推理引擎。

## 当前状态

- 阶段：**Phase 0（规划与骨架）**
- 上游：**尚未选型**，选型结论必须记录在 `docs/UPSTREAM_EVALUATION.md`
- 功能：尚未提供可运行服务

## 目标使用体验

后续将提供语义稳定的一键入口：

- `setup`：检查环境并安装依赖
- `start`：启动工作台及所选上游
- `stop`：安全停止相关进程
- `doctor`：诊断系统、运行时、GPU、端口、目录和依赖
- `update`：在保留配置和回滚能力的前提下更新

这些命令目前只是产品契约，Phase 0 不应伪装成已实现。

## 目录

- `configs/`：可提交的默认配置和配置模板
- `docs/`：架构、路线图与上游评估记录
- `examples/`：最小可复现用例
- `models/`：仅保存模型获取与放置说明，不保存权重
- `presets/`：可复用生成预设
- `scripts/`：未来的 setup/start/stop/doctor/update 入口
- `src/`：工作台自身代码与上游适配层
- `tests/`：自动化测试

## 安全与仓库卫生

不得提交模型权重、密钥、真实 `.env`、生成图片、日志、缓存或其他运行产物。只提交可审查的代码、配置模板、文档和小型测试夹具。

许可证将在上游选型与兼容性审查后确定。
