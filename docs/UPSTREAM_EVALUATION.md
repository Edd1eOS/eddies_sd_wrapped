# 上游项目评估

## 当前结论

**尚未选型。** Phase 0 不预设最终上游，也不把候选源码直接放入本仓库。

## 必评维度

1. 许可证、模型许可与再分发边界
2. 活跃维护、安全响应与发布稳定性
3. Windows、macOS、Linux 及主流 GPU/CPU 兼容性
4. 安装可复现性、冷启动时间与磁盘占用
5. API 稳定性、无头运行、进程关闭与健康检查能力
6. 图片生成质量、性能、显存管理与批处理能力
7. 扩展机制、插件隔离与升级风险
8. 日志、诊断、离线运行和代理网络支持
9. 文档质量、社区规模与长期维护成本
